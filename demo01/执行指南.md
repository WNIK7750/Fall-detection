## 🔧 常见问题

### Q1: pip install 报错怎么办？

**错误**: `Microsoft Visual C++ 14.0 is required`
**解决**: 下载安装 Visual C++ 运行时
- 地址: https://aka.ms/vs/17/release/vc_redist.x64.exe

---

### Q2: MediaPipe 安装失败？

**解决**:
```powershell
pip install mediapipe --no-cache-dir
```

如果仍然失败，使用替代方案：
```powershell
pip install opencv-python-headless
```

---

### Q3: 训练太慢？

**解决**: 减少训练epoch或批次大小
编辑 `train_lstm.py`:
```python
BATCH_SIZE = 16  # 从32改为16
EPOCHS = 50      # 从100改为50
```

---

### Q4: 显存不足(OOM)？

**解决**: 使用CPU训练
编辑 `train_lstm.py`:
```python
DEVICE = torch.device("cpu")  # 强制使用CPU
```

## 📊 数据集信息

- **数据集**: URFD (University of Rzeszów Fall Detection)
- **视频总数**: 70个
- **训练集**: 49个 (21摔倒 + 28正常)
- **验证集**: 10个 (4摔倒 + 6正常)
- **测试集**: 11个 (5摔倒 + 6正常)
- **特征维度**: 10维 (20帧滑动窗口)
