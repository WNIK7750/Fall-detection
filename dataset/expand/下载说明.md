## CAUCAFall Dataset ⏳ 需要手动下载

Mendeley Data 需要登录账号，无法直接通过脚本下载。请按以下步骤操作：

### 步骤1：访问数据集页面
```
https://data.mendeley.com/datasets/7w7fccy7ky/4
```

### 步骤2：注册/登录 Mendeley 账号
- 免费注册：https://www.mendeley.com/reference-management/account-management
- 支持微信/邮箱注册

### 步骤3：下载数据集
1. 登录后在数据集页面点击 **"Download All"** 按钮
2. 下载完整打包文件（约数GB，包含100个AVI视频）
3. 下载完成后将文件放入：
   ```
   dataset/expand/caucafall/
   ```

### 步骤4：解压并整理
下载的文件解压后，应包含以下结构：
```
caucafall/
├── Subject1/
│   ├── Fall/       (5个Fall视频)
│   ├── ADL/        (5个ADL视频)
│   ├── Fall.csv
│   └── ADL.csv
├── Subject2/
│   └── ...
├── ...
└── Subject10/
```
